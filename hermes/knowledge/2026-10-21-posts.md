## 2. Hermes Agent — 160 PRs merged 20 Oct 2026 (HermesWatcher / Luke The Dev)

Source: https://x.com/hermeswatcher/status/2112861723200004446

Key capabilities added or improved:

- **Krea 3**: Image generation + editing through the managed gateway (default for paid subscribers). Supports up to 4 reference images and 1K/2K controls.
- **Cua Spaces**: Isolated Linux machine that Hermes can use for terminal, file, and code tools; watchable live.
- **Cursor ACP**: Run Hermes on a Cursor subscription via the official Cursor CLI while Hermes retains control of tools and approvals.
- **Hermes Board**: Shared Miro-like whiteboard inside Desktop for diagrams, notes, connections, and live co-editing.
- **MCP Plugin Creator**: Scaffold, validate, and turn an existing MCP server into a portable Hermes plugin.

Additional notable changes from the full list:
- Desktop Capabilities catalog redesigned around Skills / Plugins / Connectors / Tools

- Kanban workers regain `session_search` + `delegate_task`; timeouts recorded as `timed_out`
- Telegram DM topics: first message of a new topic stays in that topic
- 80+ plugin catalog adds/bumps (Requesty, cursor-acp, Yandex Calendar, Tidal, Windows Credential Manager, etc.)
- Security: plugin updates can override a caution scan with `--force` or Desktop dialog
- Gateway lifecycle guards (never touches another home, refuses to stop while sessions live)
