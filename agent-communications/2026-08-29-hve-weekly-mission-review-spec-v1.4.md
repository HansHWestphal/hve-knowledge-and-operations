## CEO reading recommendation

Each weekly report must select one **top reference for Hans to read closely**
from the credible URLs found in the in-scope daily skill-recommendation
artifacts. Selection must be based on:

- alignment with the dominant cross-channel weekly theme
- direct usefulness for the highest-ranked week-ahead mission actions
- credibility and reviewability of the reference
- practical relevance to the current HVE-LIFE-OS stage

The report must include:

- reference title and URL
- source Cron artifact and date
- why it matters now
- the ranked next-week action it supports
- two or three concrete reading questions or takeaways

The report must not choose a link solely because it appeared most frequently.
If no suitable reference is available, state that clearly rather than inventing
or substituting a source.

This section is a decision-support recommendation only. It must not open links,
send them, purchase access, or take any external action automatically.

## Report order change

Insert **CEO reading recommendation** immediately after the cross-channel
executive synthesis and before the mission conclusion.
