# HVE Weekly Mission Review - v1.3 Contract Amendment

**Date:** August 29, 2026  
**Status:** Draft for CEO review  
**Amends:** `2026-08-29-hve-weekly-mission-review-spec-v1.2.md`

## Purpose of this revision

This revision clarifies how the weekly report should interpret sources that
were not yet commissioned during an earlier reporting period and adds an
executive synthesis that connects all available channels into one weekly
mission narrative.

## 1. Source commissioning state

Source coverage must distinguish between:

- `available`: the source was commissioned and collection ran
- `partial`: the source was commissioned but coverage was incomplete
- `not_yet_commissioned`: the source was not part of the active reporting
  configuration during the period
- `unavailable`: the source was expected but could not be read or collected
- `excluded`: deliberately outside the approved scope

A `not_yet_commissioned` source is historical context, not a system failure,
blocker, or negative progress finding. The report must state the first period
in which that source enters the baseline. This prevents later-added sources
from creating false historical deficits.

## 2. Executive synthesis requirement

Every report must include an **Executive synthesis** immediately after the
title and executive status. It must:

1. Name the dominant theme of the reporting period.
2. Integrate evidence across all available channels rather than repeating
   separate source summaries.
3. Explain what the combined pattern means for the HVE mission, Five Wealth
   progress, and HVE-LIFE-OS offer development.
4. Distinguish verified cross-channel patterns from attributed statements and
   inferences.
5. Identify the most important momentum signal, constraint, and decision.

The synthesis is not a replacement for the evidence ledger or source coverage
section. It is a concise decision-oriented interpretation grounded in those
sections.

## 3. Required report order

The report order is now:

1. Title, reporting period, generation metadata, and executive status
2. Cross-channel executive synthesis and dominant weekly theme
3. Mission conclusion
4. Source coverage and commissioning state
5. Privacy, retention, and restricted-record handling
6. Verified accomplishments
7. Decisions, commitments, and deadlines
8. Five Wealth matrix with prior-week comparison
9. Five-by-five offer portfolio completeness
10. Managed-retainer readiness
11. HVE-LIFE-OS capability and launch readiness
12. Blockers, risks, contradictions, and unknowns
13. Ranked next-week action agenda
14. Decisions requiring Hans's judgment
15. Evidence appendix and audit details
